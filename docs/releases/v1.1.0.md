# v1.1.0 · 开局讲解与关键局面思考

新手可以先理解布局目的，在熟悉的走法上快速练习，把计算时间留给关键选择。

## 新功能

- **三节开局课**：中炮对屏风马、仙人指路、飞相开局，每节 6 回合，可执红或执黑。提供学习目标、双方逐手讲解、常见误区与可选示范。
- **课程思考停点**：每方两个预设停点，先独立思考，再按需看思路提示或引擎候选；确认后继续落子。
- **实战关键局面提醒**：被将军、大子吃子、新出现直接吃大子的合法着法、首次脱离课程，以及引擎发现己方杀棋或候选评分差距明显时，提醒停下来比较。
- **学习进度保存**：保留课程演练次数、未完成停点与已看的提示；错题重练结束后可返回原课程及停点。
- **课程衔接实战**：偏离后可研究变招或退回主线；课程完成后先回顾要点，再从同一局面继续与皮卡鱼对弈。

熟悉的课程可选择“仅跟谱练习”，也可关闭关键局面提醒。红黑局势评分在停点期间继续更新。

## 使用与下载

本 Release 的 `xiangqi-study-v1.1.0-source.zip` 是应用源码包，不含 Node.js、皮卡鱼引擎或 NNUE 权重，也不是免安装可执行程序。

Windows 使用步骤：

1. 安装 Node.js 18 或更高版本，解压源码包。
2. 在解压目录运行 `npm.cmd ci --omit=dev`。
3. 按 [README](https://github.com/xxzzh/xiangqi/tree/v1.1.0#首次安装windows) 将官方皮卡鱼引擎、匹配 NNUE 和许可文件放入 `engine/`。
4. 双击 `启动研习室.cmd`，打开本地棋盘。

已有安装可更新源码后刷新页面；原有浏览器进度与错题本继续保留。更新前如有重要棋局，建议导出 PGN 留存。

## 验证与范围

- 35 项自动化测试通过，包含课程合法性、避免炮马兵直接吃车的主线检查、停点与存储恢复、错题返回、真实引擎响应及多页面隔离。
- 浏览器验收课程起步、提示、停点锁定、刷新恢复、完成回顾与继续实战。
- 三节主线的全部 39 个起始/中间局面已用本机皮卡鱼复核，修正了不适合新手演练的炮线丢车走法。

课程是原创教学示例，不是唯一最优变化或名家棋谱。自动提醒依据局面规则和有限时间搜索，不能覆盖所有妙手、陷阱或关键选择；评分不是胜率，完成次数也不代表已掌握全部变招。

基础项目沿用 MIT 许可与原作者署名；引擎及 NNUE 来源和许可见 [THIRD_PARTY.md](https://github.com/xxzzh/xiangqi/blob/v1.1.0/THIRD_PARTY.md)。
