# v1.2.0 · Windows 免安装整合版

普通棋友现在可以下载整合包，完整解压后双击启动，直接进行本地象棋训练。

## 下载哪个文件

- **`xiangqi-study-v1.2.0-windows-x64.zip`**：普通用户选择此包，已包含 Node.js 24.22.2、生产依赖、Pikafish 2026-09-06 和匹配 NNUE，首次启动无需联网，无需安装 Node.js、npm 或另配引擎。
- **`xiangqi-study-v1.2.0-windows-x64.zip.sha256`**：整合包 SHA256 校验文件。
- **`xiangqi-study-v1.2.0-source.zip`** 或 GitHub 的 Source code：开发者源码包，需要自行安装运行环境与引擎。

面向 Windows 10/11 x64（Intel/AMD 64 位），需要本机已有的现代浏览器；32 位 Windows 和原生 ARM64 不适用此包。

## 开始使用

1. 将整个 ZIP 解压到“文档”、桌面等有写入权限的文件夹。
2. 双击 **`启动研习室.cmd`**，浏览器自动打开本地棋盘。
3. 选择课程并点击“开始讲解课程”，或者进入引擎陪练。
4. 完全退出时，双击 **`停止研习室.cmd`**。

不需要账号或管理员权限，训练在本机进行。开局讲解、思考停点、红黑评分和错题本继续保留。请完整解压后再运行，不要在压缩软件内直接启动。

## 启动体验改进

- 优先使用包内运行环境，检查依赖、引擎、NNUE 与目录写入权限，缺文件时给出中文提示。
- 本目录重复启动会复用服务；端口被其他程序或另一份整合包占用时自动避让，不会结束其他程序。
- 服务只监听 `127.0.0.1`；停止脚本核对本目录进程身份，并结束其引擎子进程。
- 提供可复现的构建脚本、逐文件 SHA256 清单与实际 ZIP 验收脚本。
- ZIP 文件名统一使用 UTF-8，通过 Windows 自带 ZIP 解压功能验收，避免不同系统语言导致中文启动文件名乱码。

课程、错题和棋局保存在浏览器中。更新前先导出重要 PGN、停止旧版，再完整解压新版；尽量使用同一浏览器和本地网址。更换端口会使用另一份浏览器存储，原记录不会自动迁移。
